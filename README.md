# dArkOS_IMAX_Player
Enjoy the true IMAX Experience at home by watching movies spread over multiple R36S'!


--Rough Steps--

Copy this script over to 2 or 3 different R36S devices running dArkOSRE

Put all of your movies in the /roms/movies folder

Run the script on all devices and select the same movie on each

Split the video into either 2 or 3 parts and press PLAY at the same time on each to get them in sync
